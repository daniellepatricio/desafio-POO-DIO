O projeto busca aproximar conceitos teóricos da POO com uma implementação prática e organizada em Java.

## 📚 Conceitos de Programação Orientada a Objetos (POO)

A Programação Orientada a Objetos é um paradigma baseado na interação entre objetos, aproximando o mundo real do mundo virtual por meio de classes, atributos, métodos e objetos.

### 🔺 Pilares da POO

- **Abstração**  
  Foco nos aspectos essenciais de um domínio, ignorando detalhes irrelevantes.

- **Encapsulamento**  
  Ocultação da implementação interna, facilitando a manutenção e evolução do sistema.

- **Herança**  
  Permite que uma classe reutilize e estenda comportamentos de outra classe.

- **Polimorfismo**  
  Capacidade de tratar objetos de diferentes classes por meio de uma referência comum.

---

## 🧠 Conceitos Fundamentais

- **Domínio**: Representa o problema do mundo real a ser modelado.
- **Classe**: Estrutura que define atributos e comportamentos.
- **Atributo**: Características de uma classe.
- **Método**: Ações ou comportamentos da classe.
- **Objeto**: Instância de uma classe.
- **Instância**: Criação de um novo objeto a partir de uma classe.

---

## 💡 Linguagem de Programação x Paradigma

- **Linguagem de Programação**: Ferramenta usada para escrever instruções para o computador.
- **Paradigma de Programação**: Modelo que define a forma de pensar e estruturar a solução de um problema.

### Exemplos de Paradigmas

- **Imperativo**: Estruturado, Concorrente, Orientado a Objetos  
- **Declarativo**: Funcional, Lógico
